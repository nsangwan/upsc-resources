# Contributing to Awesome UPSC Resources 📚

Thank you for your interest in contributing to the **Awesome UPSC Resources** repository curated by **[UPSC Club](https://upscclub.com/)**!

## Ways to Contribute

- **Add high-yield study resources**: Add links to open-access notes, government reports, or toppers' strategies.
- **Fix broken links**: If any syllabus link or PDF document is missing or moved, open a PR to fix it.
- **Improve syllabus coverage**: Expand micro-topics for GS Papers I to IV or Optional subjects.

## Contribution Guidelines

1. **Fork** the repository and clone it to your local environment.
2. Create a clean branch:
   ```bash
   git checkout -b feature/your-addition
   ```
3. Ensure all links point to authoritative, publicly accessible, or verified free study materials.
4. Keep Markdown formatting consistent, clean, and categorized under appropriate sections.
5. Commit with a concise message:
   ```bash
   git commit -m "docs: add GS3 internal security resource guide"
   ```
6. Push to your fork and submit a **Pull Request**.
